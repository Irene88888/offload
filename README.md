# 磅單追蹤平台

用來取代「每次把磅單照片貼進 Claude 對話、請它讀資料再更新追蹤表」的做法。
這個平台在**本機**執行，上傳照片、OCR 辨識、算統計、產生 Excel 全部都是
一般程式邏輯，不會呼叫任何 LLM，所以不會累積 token 費用；就算 OCR 對手寫字
辨識不準，你也只是在表單裡手動修正欄位，跟打字進聊天室比起來一樣快，但完全
不花 API 成本。

## 功能

- **新增紀錄**：上傳磅單照片 → 本機 Tesseract OCR 嘗試辨識文字 → 用規則
  （不是 AI）猜測重量、日期、車號等欄位並標黃提示 → 你核對後送出。也可以
  完全不上傳照片、直接手動輸入。
- **紀錄列表**：篩選（地點／是否收到計價單／付款狀態／日期區間／關鍵字搜尋）、
  就地編輯、刪除。
- **統計摘要**：對應原本 Excel 的「統計摘要」「依日期統計」兩個分頁，即時計算。
- **匯出 Excel**：一鍵匯出成跟你原本檔案一樣結構的 .xlsx（含「說明」「磅單紀錄」
  「統計摘要」「依日期統計」四個分頁，下拉選單也會保留）。
- **匯入 Excel**：把你現有的《e9ca7387\_\_\_\_\_\_0922.xlsx》或任何同格式的舊檔
  上傳，一次把既有資料匯入資料庫，之後就都在平台上操作。

## 快速開始（Docker，建議）

```bash
docker compose up --build
```

啟動後開瀏覽器到 http://localhost:8000 。資料庫與上傳照片存在 `./data`
目錄（已掛載成 volume），砍掉容器也不會遺失資料。

## 不用 Docker 直接執行

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# OCR 需要系統安裝 tesseract 執行檔與繁體中文語言包：
#   macOS:   brew install tesseract tesseract-lang
#   Debian/Ubuntu: sudo apt install tesseract-ocr tesseract-ocr-chi-tra
#   Windows: 安裝 https://github.com/UB-Mannheim/tesseract/wiki，
#            安裝時勾選 Chinese (Traditional)

uvicorn backend.app.main:app --reload --port 8000
```

沒裝 tesseract 也能用——OCR 那一步會直接跳過並提示你改用手動輸入，其他功能
（表單、篩選、統計、匯出入 Excel）都正常。

## 第一次使用：把舊 Excel 資料匯入

1. 啟動平台，打開「紀錄列表」頁。
2. 按「匯入 Excel（原舊版磅單追蹤表）」，選擇你現有的追蹤表檔案。
3. 平台會讀取「磅單紀錄」分頁，把每一列建成一筆紀錄，並自動把用過的
   地點／狀態值加進下拉選單。
4. 之後所有更新都在平台上做；需要給別人看報表時，用「匯出 Excel」
   重新產生最新的 .xlsx 即可。

## 資料模型

比原本的 15 個欄位多了兩個：**傳票編號/序號**、**車號**——這兩個欄位在你原本
的「說明」分頁裡有定義，但實際使用時被塞進「備註」欄位的自由文字裡
（例如「序36/車號KEB-8800」），拆成獨立欄位後之後要篩選/核對會更方便，
匯入舊檔案時如果抓不到，欄位就留空，不影響其他資料。

另外新增一個「計入統計加總」核取方塊，對應你原本在備註裡手寫「金額併入
序XX，此列不重複記金額」的情況——勾掉之後，這筆的金額就不會被算進統計
摘要與依日期統計，也不需要再手動維護一個「有效金額」欄位是否留空。

## 安全性提醒

這是給個人／單一使用者在本機或內部網路使用的簡易工具，**沒有帳號登入機制**。
如果要放到公開網路上存取，請自行加上反向代理 + 基本認證（例如 Caddy/Nginx
的 Basic Auth），不要直接把 8000 port 暴露在公網。
